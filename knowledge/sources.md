# Sources

site's rules will cite chunks. "Read" is the date the source was opened and
read for this knowledge base; a source with no read date is never cited.

Tiers: A peer-reviewed, B preprint/technical report, C official docs or guide,
D practitioner/vendor blog, E course materials and team notes (see README.md).

## Notes

- **Not in the team's bibliography.** The Anthropic and OpenAI guides were
  added while building the site. The site's `src/lib/sources.ts` currently
  says every source it lists is "cited in AI Assignment 4", which is not
  true for these two; to be corrected when the rules are re-linked.
- **ENMGT 5405 claims in the site.** `src/lib/sources.ts` says the lecture
  slides back "skills, MCP, system prompts, Claude Cowork and the autonomy
  spectrum". The team notes cover skills, MCP, system prompts and Cowork, but
  say nothing about an autonomy spectrum, and the slides are unavailable. That
  attribution cannot be verified and should be dropped or confirmed.
- **"Anthropic. (2026). Claude Sonnet 5.5"** is listed in the team's
  bibliography as a tool used while researching. It is not a source of
  claims and is not cited here.
